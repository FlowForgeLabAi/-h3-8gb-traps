# Third-party content

This repository contains **only scripts, measurements and generated workflow
JSON**. It does not include or redistribute:

- model weights (main model, text encoder, video/audio VAE)
- LoRA files
- ComfyUI custom-node code

The workflow JSON files are generated artifacts that **reference model
filenames by name**. You must supply those files yourself; nothing in this
repository grants any right to them.

Model files remain under the terms of their own publishers. `ComfyUI` and
`ComfyUI-VideoHelperSuite` remain under their own licences.
